# Front-End Technology Projects

## Project Overview

FFT_Karthikeyan is a collection of front-end development projects, case studies, forms, portfolio materials, and web-page prototypes. The repository demonstrates practical use of HTML, CSS, JavaScript, responsive layouts, forms, and user-interface design.

## Included Work

- Portfolio and resume pages.
- Car website prototype.
- Login and registration pages.
- Calculator and animation mini-projects.
- Student details and timetable pages.
- Job application and capstone case studies.

## Purpose

This repository acts as a portfolio of front-end learning and project work, showing progression from individual UI exercises to complete multi-page web experiences.
